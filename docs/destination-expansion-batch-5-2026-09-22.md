# Destination expansion batch 5 — scientific intake

Status: **planning-only; no destination is published by this decision alone**  
Reviewer: SOL-assisted scientific intake  
Target: 40 new destinations, taking the catalogue from 335 to 375 only after every source and release gate passes.

## Selection rule

The batch adds clearly named hiking areas that are not already present in the catalogue. Each intake coordinate represents one documented trail hub, trailhead or walking area. It does not claim to be a whole-park centroid, a route average or a current-conditions observation. Public output must retain the existing scope: **one selected representative model-grid cell; not a whole-region or route-specific average**.

Coordinates are resolved to the nearest ERA5-Land 0.1-degree model cell. A candidate is withheld when the selected cell fails the land-fraction, source-completeness, observation-validity, persistent-snow, independent-climate or recommendation gate. No threshold may be relaxed to reach the target count.

The full hourly time series must return unmasked, complete observations before any of them can enter the catalogue.

6. Run the complete deterministic build, tests, science audit and deployment-budget guard before committing or deploying.
