# Licensing and attribution

No third-party climate, DEM, OSM, or photographic data is distributed in the current fixture build. The topographic artwork is generated in CSS.

Before production activation, this document must be completed with the then-current ERA5-Land dataset identifier/DOI, Copernicus DEM GLO-30 attribution and user obligations, any OSM ODbL implications, and per-image author/license/source/transformation records. This is an operator/legal approval gate and is not auto-approved by code.
